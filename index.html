1 · Concepto

Integral indefinida y antiderivada

F′(x) = f(x)
∫ f(x) dx = F(x) + C
La integral indefinida representa una familia de antiderivadas y no una sola función.

3 · Integración

Integral de 2x

∫ 2x dx = 2 ∫ x dx
= 2(x²/2) + C
= x² + C
ReglaInversa de la potencia
Antiderivadax² + C
Conjunto solución{x² + C : C ∈ ℝ}
4 · Verificación

Comprobación por derivación

F(x) = x² + C
F′(x) = 2x + 0
F′(x) = 2x ✓
Al derivar el resultado se recupera la función original.
5 · Función trigonométrica

Segunda función: f₂(x) = sen(x)

f₂(x) = sen(x)
∫ sen(x) dx = −cos(x) + C
La derivada de −cos(x) es sen(x), por eso −cos(x) es una antiderivada de sen(x).
FamiliaTrigonométrica
Antiderivada−cos(x) + C
Conjunto solución{−cos(x)+C : C ∈ ℝ}
6 · Verificación

Comprobación de la función trigonométrica

G(x) = −cos(x) + C
G′(x) = sen(x) + 0
G′(x) = sen(x) ✓
La constante desaparece al derivar y vuelve a aparecer la función inicial.
7 · Constante de integración

Por qué aparece C

x²,   x² + 2,   x² − 5
d/dx (x² + C) = 2x
Distintos valores de C producen funciones diferentes, pero todas conservan la misma derivada.
Cambiar C desplaza la parábola verticalmente sin cambiar su derivada.
Impacto analíticoC distingue las soluciones
Impacto gráficoTraslación vertical
Error frecuenteOmitir + C

Enfoque algorítmico y enfoque conceptual

ConclusiónLos dos enfoques se complementan
